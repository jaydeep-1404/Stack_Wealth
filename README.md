# stackwelth

## Description

Dealsify Books is a Flutter app that helps users discover and manage books. It integrates Firebase for storage and implements multiple Firebase projects for development, staging, and production environments.

## Prerequisites

Before running the app locally, make sure you have the following tools installed:

- [Flutter SDK](https://flutter.dev/docs/get-started/install)
- [Dart SDK](https://dart.dev/get-dart)
- [Android Studio](https://developer.android.com/studio) (for Android development)
- [Xcode](https://developer.apple.com/xcode/) (for iOS development, macOS only)
- [Git](https://git-scm.com/)

## Flutter & Dart Versions

Ensure the following versions of Flutter and Dart are used for consistency:

- Flutter version: `3.29.2`
- Dart version: `3.7.2`

for create build in macos run this commands :

- 1: chmod +x builds.sh
- 2: ./builds.sh
- and select build variant

- APK also available in Github Actions
